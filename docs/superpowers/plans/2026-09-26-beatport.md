# Beatport Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Beatport como cuarto proveedor de búsqueda, con login de la cuenta del usuario, que al aplicar rellena también BPM, tonalidad, mix e ISRC.

**Architecture:** Cliente `main/beatport.ts` con el patrón de Deezer (limitador, caché, `activity.track`), sobre una sesión OAuth `main/beatportSession.ts` con dependencias inyectadas. Credenciales cifradas con `safeStorage` en claves locales e internas de settings, cambiadas solo por IPC propio. `ReleaseTrack` gana cuatro campos opcionales que `buildReleaseMeta` aplica.

**Tech Stack:** Electron (main/preload/renderer), TypeScript, React 19, Vitest, Biome, i18next.

**Spec:** `docs/superpowers/specs/2026-09-26-beatport-design.md`

  - `/auth/o/token/` con `grant_type=authorization_code` devuelve `{access_token:'A1', refresh_token:'R1', expires_in:36000}`; con `grant_type=refresh_token` devuelve `{access_token:'A2', refresh_token:'R2', expires_in:36000}` o 400 según el test.

  Casos (cada nombre dice el porqué):
  - `logs in once and reuses the token while it is fresh, so a batch does not hammer the login`: dos `getAccessToken()` → `'A1'` las dos, 1 login.
  - `ten searches arriving with no token share one login instead of racing ten`: `Promise.all` de 10 → 1 llamada a `/auth/login/`.
  - `renews with the refresh token when the access token expires, without the password`: `now` avanza 36000 s → `'A2'`, 0 logins nuevos.
  - `logs in again when the refresh is refused, so the background sweep never goes silent`: refresh 400 → nuevo login → `'A1'`.
  - `invalidate after a 401 forces a new token on the next call`: `invalidate()` y `getAccessToken()` no devuelve el token anterior.
  - `a password changed on beatport.com surfaces as bad credentials and stops retrying`: credenciales `{u, wrong}` → rechaza con `beatportBadCredentials`; una segunda llamada rechaza igual sin llamar a `/auth/login/` otra vez; tras `reset()` vuelve a intentarlo.
  - `without stored credentials it asks the user to connect`: `credentials: () => null` → `beatportNotConnected`, 0 fetch.
  - `validate checks the account without storing a token`: `validate({u,p})` resuelve; `validate({u,x})` rechaza con `beatportBadCredentials`; tras `validate` ok, `getAccessToken()` con `credentials: () => null` sigue rechazando con `beatportNotConnected`.
  - `a rotated client id is looked up again once, so a Beatport redeploy does not break everyone`: el primer `/auth/o/token/` responde 401 `{"error":"invalid_client"}` → se vuelve a pedir `/docs/` una vez y el segundo intento da `'A1'`. Implementación: en `login`, si `res2.status === 401`, `clientId = undefined` y repetir authorize + token una sola vez.
  - `a rejected attempt releases the in-flight slot so the next call retries`: primer `/auth/login/` lanza error de red → rechaza con `beatportUnavailable`; segundo intento logra `'A1'`.

  ```ts
  import { errorWithKey } from '../shared/errorKeys'
  import { REQUEST_TIMEOUT_MS, USER_AGENT } from './http'

  export const BEATPORT_API = 'https://api.beatport.com/v4'
  const REDIRECT_URI = `${BEATPORT_API}/auth/o/post-message/`
  const EXPIRY_MARGIN_MS = 60_000

  interface Token { access: string; refresh?: string; expiresAt: number }
  interface TokenBody { access_token?: string; refresh_token?: string; expires_in?: number }

  export function createBeatportSession(deps: BeatportSessionDeps): BeatportSession {
    let clientId: string | undefined
    let token: Token | undefined
    let inflight: Promise<string> | undefined
    let rejected = false

    const request = async (url: string, init: RequestInit = {}): Promise<Response> => {
      try {
        return await deps.fetch(url, {
          ...init,
          headers: { 'User-Agent': USER_AGENT, ...(init.headers ?? {}) },
          signal: AbortSignal.timeout(REQUEST_TIMEOUT_MS),
        })
      } catch (err) {
        throw errorWithKey('beatportUnavailable', String(err))
      }
    }

    const discoverClientId = async (): Promise<string> => {
      if (clientId) return clientId
      const html = await (await request(`${BEATPORT_API}/docs/`)).text()
      for (const src of html.match(/\/static\/btprt\/[^"']+\.js/g) ?? []) {
        const js = await (await request(`https://api.beatport.com${src}`)).text()
        const found = js.match(/API_CLIENT_ID:\s*['"]([^'"]+)['"]/)?.[1]
        if (found) return (clientId = found)
      }
      throw errorWithKey('beatportUnavailable', 'client id')
    }

    const tokenFrom = (body: TokenBody): Token => {
      if (!body.access_token) throw errorWithKey('beatportUnavailable', 'token')
      return {
        access: body.access_token,
        refresh: body.refresh_token,
        expiresAt: deps.now() + (body.expires_in ?? 0) * 1000,
      }
    }

    const exchange = async (params: Record<string, string>): Promise<Response> =>
      request(`${BEATPORT_API}/auth/o/token/`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
        body: new URLSearchParams(params),
      })

    const login = async ({ username, password }: BeatportCredentials): Promise<Token> => {
      const id = await discoverClientId()
      const res = await request(`${BEATPORT_API}/auth/login/`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ username, password }),
      })
      if (res.status === 403 || res.status === 401) throw errorWithKey('beatportBadCredentials')
      if (!res.ok) throw errorWithKey('beatportUnavailable', String(res.status))
      const cookie = res.headers.getSetCookie().map((c) => c.split(';')[0]).join('; ')
      const auth = await request(
        `${BEATPORT_API}/auth/o/authorize/?response_type=code&client_id=${id}&redirect_uri=${encodeURIComponent(REDIRECT_URI)}`,
        { headers: { Cookie: cookie }, redirect: 'manual' },
      )
      const code = new URL(auth.headers.get('location') ?? '', BEATPORT_API).searchParams.get('code')
      if (!code) throw errorWithKey('beatportUnavailable', `authorize ${auth.status}`)
      const res2 = await exchange({ code, grant_type: 'authorization_code', redirect_uri: REDIRECT_URI, client_id: id })
      if (!res2.ok) throw errorWithKey('beatportUnavailable', `token ${res2.status}`)
      return tokenFrom((await res2.json()) as TokenBody)
    }

    const renew = async (refresh: string): Promise<Token | undefined> => {
      const res = await exchange({ grant_type: 'refresh_token', refresh_token: refresh, client_id: await discoverClientId() })
      return res.ok ? tokenFrom((await res.json()) as TokenBody) : undefined
    }

    const fresh = async (): Promise<string> => {
      if (token && token.expiresAt - EXPIRY_MARGIN_MS > deps.now()) return token.access
      if (token?.refresh) {
        const renewed = await renew(token.refresh)
        if (renewed) return (token = renewed).access
      }
      const credentials = deps.credentials()
      if (!credentials) throw errorWithKey('beatportNotConnected')
      if (rejected) throw errorWithKey('beatportBadCredentials')
      try {
        return (token = await login(credentials)).access
      } catch (err) {
        if (err instanceof Error && err.message.startsWith('beatportBadCredentials')) rejected = true
        throw err
      }
    }

    return {
      getAccessToken() {
        inflight ??= fresh().finally(() => {
          inflight = undefined
        })
        return inflight
      },
      invalidate() {
        if (token) token = { ...token, expiresAt: 0 }
      },
      async validate(credentials) {
        await login(credentials)
      },
      reset() {
        token = undefined
        rejected = false
      },
    }
  }
  ```
  Antes de fijar `err.message.startsWith(...)`, leer `errorWithKey`/`errorKeyOf` en `shared/errorKeys.ts` y usar `errorKeyOf(err.message) === 'beatportBadCredentials'`, que es la forma que ya usa el código.
