# Microsoft Store listing for Surco

Texts for the first submission in Partner Center (product `9P8C4M673334`). The package
declares five languages, so Partner Center asks for a listing in each. Everything here
is about the Windows app: Apple Music is macOS only and is left out on purpose.

Price: **Free**. Category: **Music**. Privacy policy URL:
https://getsurco.app/en/privacy (Spanish: https://getsurco.app/privacidad).

## Restricted capability justification (`unvirtualizedResources`)

> Surco edits the user's DJ libraries in place (rekordbox keeps its collection under
> %APPDATA%\Pioneer) and keeps copies of the user's original audio files under
> %APPDATA%\Surco so they can be restored. With write virtualization these copies would be
> deleted when the app is uninstalled and would be invisible to File Explorer, and the
> settings would not be shared with the desktop installer the user may be moving from.
