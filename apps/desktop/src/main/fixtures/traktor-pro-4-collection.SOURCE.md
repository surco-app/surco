# traktor-pro-4-collection.nml

A `collection.nml` written by Traktor Pro 4 (`NML VERSION="20"`), copied unchanged from
`tests/fixtures/collection_v4_traktor_format.nml` of
https://github.com/wolkenarchitekt/traktor-nml-utils (GPL-3.0, the same licence as Surco).

It is the only real Traktor Pro 4 collection the tests have: it shows the per-cue `COLOR`
attribute Traktor Pro 3 never wrote, on some cues and not on others.
